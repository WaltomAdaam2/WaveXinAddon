# WaveXinAddon

WaveXinAddon is a Meteor Client addon for Minecraft 1.21.11.

## Features

- AutoLoginXin
- BaseFinderXin
- ChickenNametags
- ElytraFlyXin
- ElytraReplace
- NetherElytraPath
- SimpleElytraFlyPath
- SnifferNametags

## Requirements

- Java 21
- Minecraft 1.21.11
- Fabric Loader
- Meteor Client 1.21.11
- Baritone for Meteor

## Build

```bash
./gradlew clean build --stacktrace --console=plain
```

The built jar is written to `build/libs/`.
