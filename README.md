# WaveXinAddon

WaveXinAddon is a Meteor Client addon designed for the 2b2t.xin server.

## Features

* Elytra flight helper
* Simple elytra path flight
* Nether elytra path helper
* Auto login helper
* Base finder
* Elytra replacement
* Chicken nametags
* Sniffer nametags

## Requirements

* Minecraft 1.21.11
* Fabric Loader
* Fabric API
* Meteor Client
* Baritone

## Build

```bash
./gradlew clean build --stacktrace --console=plain
```

The built jar will be generated in:

```text
build/libs/
```

Use the normal jar file, not the sources jar or dev jar.

## Installation

Place the built WaveXinAddon jar into your Minecraft `mods` folder together with Fabric API, Meteor Client, and Baritone.
